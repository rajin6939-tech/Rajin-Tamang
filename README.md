# RAJIN DESIGNER — Website Starter

A responsive blue-and-white website prototype for a digital design library.

## Included
- Logo, banner, certificate, visiting card, social media and Photoshop PSD categories
- Starter cards with display price `Rs. 00.00`
- Search and category filtering
- Prototype add-product form
- Optional preview image and original file attachment
- Responsive layout and lightweight CSS animations

## Run locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Use the Admin Studio section to test adding products.

## Important: prototype, not a live e-commerce service
This version is a front-end prototype. Product data and uploaded files are stored in the current browser's local storage. They do not sync to other devices or publish to other visitors. The demo admin form is **not protected by a login**, so do not treat it as a secure admin panel. Large PSD files may exceed browser storage limits.

Before launching publicly, upgrade to a real app with:
- Authenticated admin account and server-side authorization
- Database for product records and prices
- Object storage for large PSD/AI/ZIP files
- Public preview images separated from original downloadable files
- Download access rules, upload validation and backups
- Domain configuration, HTTPS, SEO and analytics
- Payment gateway only after merchant approval (when you decide to charge)

A practical future stack: Next.js + Supabase (Auth, Postgres, Storage) + Cloudflare/Vercel hosting. Never put secret API keys in front-end JavaScript.

## Product file advice
- Preview: JPG/PNG/WebP with a watermark if desired
- Original: PSD, AI, PDF, ZIP, PNG or JPG
- Only upload files you created or have permission to distribute.
- For a free launch, `Rs. 00.00` is a display value; explain whether the download is free and show the actual original file availability clearly.
